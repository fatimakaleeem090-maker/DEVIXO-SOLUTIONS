# Devixo Solutions

## Project Description

Devixo Solutions is a responsive multi-page website designed for a
technology and digital solutions company. The website presents the
company's services, portfolio, information, and contact options through
a modern and user-friendly interface.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Website Features

- Responsive navigation menu
- Active navigation link
- Typing animation
- FAQ accordion
- Contact form validation
- Scroll-to-top button
- Responsive desktop and mobile layout
- Service cards
- Portfolio section
- Contact form

## Website Pages

1. Home
2. About
3. Services
4. Portfolio
5. Contact
## Instructions for Running the Website

### Method 1: Using Visual Studio Code and Live Server

1. Download or clone the Devixo Solutions project from GitHub.
2. Open the project folder in Visual Studio Code.
3. Make sure the following files are present:
   - index.html
   - about.html
   - services.html
   - portfolio.html
   - contact.html
   - style.css
   - script.js
4. Install the Live Server extension in Visual Studio Code if it is not already installed.
5. Open `index.html` in Visual Studio Code.
6. Right-click inside `index.html`.
7. Select **Open with Live Server**.
8. The website will open automatically in the web browser.
9. Use the navigation bar to visit the Home, About, Services, Portfolio, and Contact pages.

### Method 2: Using a Web Browser

1. Open the project folder.
2. Double-click `index.html`.
3. The Home page will open in the default web browser.
4. Use the navigation links to move between the different pages.

### Responsive Testing

The website can be tested on different screen sizes using the browser's Developer Tools.

1. Open the website.
2. Press `F12`.
3. Select the device/mobile view icon.
4. Test the website on desktop, tablet, and mobile screen sizes.
5. Check that the navigation menu and page layout work correctly.
